# Vitrual Piano

## Overview

Virtual Piano is a piano that runs on your browser and can be played by using your keyboard or by clicking the keys. This piano consists of 10 white keys and 7 black keys.

## Features

- Click-able keys: You can play the piano by clicking on individual keys or the piano.
- Keyboard: You can also play the piano by using your computer's keyboard.
- Adjustable Volume Bar: You can adjust the volume of the piano using the slider.
- Orange Keys: Checking this box off makes your white keys orange.
- Try playing Mary had a little lamb: Shows the user that keys should be pressed to play Mary had a little lamp.
